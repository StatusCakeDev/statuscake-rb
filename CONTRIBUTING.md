# How To Contribute

Contributions are not possible within this repository due to the code being
generated, however we do accept issues being raised as we strive to make this
package as useful as possible for everyone.

If this package is found to be missing in functionality, please open an issue
describing the proposed change.

## Prerequisites

You will need the following things properly installed on your computer:

- [Git](https://git-scm.com/)
- [Ruby](https://www.ruby-lang.org/en/) (2.4+)

## Installation

- `git clone <repository-url>` this repository
- `cd statuscake-rb`

## Running tests

- `bundle exec rake spec`

## Making Changes

See the contributing guide at
[devhandbook.org](https://devhandbook.org/contributing)
